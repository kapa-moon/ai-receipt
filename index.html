Find your trace files

Choose raw .jsonl trace files or an exported receipt JSON. No API key is needed to import, calculate costs, filter messages or rate results.

1 / Codex & local ChatGPT Work

~/.codex/sessions/

On Mac, open Finder → Go → Go to Folder (⌘⇧G), then paste that path. Open the year/month/day folders and select rollout-….jsonl files. A file’s folder date is its start date: it can contain many later days. Select the original and continuation files for a complete chat.

Windows: look under %USERPROFILE%\.codex\sessions\. A custom CODEX_HOME changes this location. This importer supports the observed local rollout format. Local Work logs may appear here; cloud Work and ordinary ChatGPT conversation exports are not supported token traces.

2 / Claude Code

~/.claude/projects/

Open the folder corresponding to your project, then select its session .jsonl file(s). Windows: %USERPROFILE%\.claude\projects\. A custom CLAUDE_CONFIG_DIR changes this location. Official transcript documentation ↗

3 / Claude Cowork on Mac (experimental)

~/Library/Application Support/Claude/local-agent-mode-sessions/

Look inside account/session folders for audit.jsonl. This location and the record format are observed implementation details; they may differ between versions. A normal Claude chat export is not a metered Code/Cowork trace.

What to select

  • Trace record formats vary between versions; a file without supported usage records cannot produce a cost estimate. Select files from one chat/project together. Don’t select your entire history unless you intend to combine it into one topic.
  • Do not select auth.json, API keys, .env files or history.jsonl. Prompt-only history lacks the usage records needed for this receipt.
  • Start with All dates. Date filters operate on complete user-message turns.
  • Export receipts to keep imported data and reflections across reloads.

Your selected files stay in your browser. “Upload” opens a local file picker; this app does not send your trace files to a server. The owner-provided sample traces are already hosted with the app and can be read by anyone with access. Optional mini-model summaries require an OpenAI API key in the command-line enrichment tool; that tool explicitly sends selected excerpts to OpenAI.
